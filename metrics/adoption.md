# Arid Adoption Metrics

PyPI download statistics are recorded periodically using:

```bash
pypistats recent arid
```

PyPI downloads are not unique users or installations. These figures are tracked as an indicator of package activity and adoption trajectory.

Record one snapshot per week, ideally on the same day, to make the rolling 7-day and 30-day windows easier to compare over time.
