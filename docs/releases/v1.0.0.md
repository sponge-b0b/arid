# Arid 1.0.0 — First Stable Release

**Released:** August 14, 2026

Arid 1.0.0 is the first stable release of Arid: a fast, Python-specific duplicate-code checker written in Rust and designed as a focused replacement for Pylint `R0801` that complements Ruff.

This release establishes the core Arid contract: exact duplicate detection after Python-aware normalization, deterministic reporting, accurate source locations, and a deliberately narrow CLI built for real Python repositories.

## Highlights

- Detect duplicate Python source across files and within the same file.
- Ignore comments, docstrings, imports, and function signatures when configured.
- Preserve physical source locations even when normalized content differs from the original source layout.
- Report concise `DUP001` findings with structural context and scope.
- Support deterministic duplication metrics and machine-readable JSON output.
- Read project configuration from `[tool.arid]` in `pyproject.toml`.
- Support explicit worker counts for parallel file preparation while preserving deterministic results.
- Respect `.gitignore`, configured exclusions, hidden-file controls, and source-level suppression regions.

## Example

```bash
ruff check .
arid .
```

For machine-readable output:

```bash
arid . --json
```

To include original source text with findings:

```bash
arid . --show-source
```

## Compatibility

`1.0.0` defines Arid's first stable CLI and duplicate-detection contract. The project remains intentionally Python-only and does not attempt semantic, fuzzy, structural, or multi-language clone detection.

## Install or upgrade

With `uv`:

```bash
uv tool install arid
```

With `pip`:

```bash
python -m pip install arid
```
