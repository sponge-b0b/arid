# Arid 2.2.3 — Prepare the GitHub Action for Marketplace

Arid 2.2.3 is a small integration and packaging release that prepares Arid's existing GitHub Action for publication in GitHub Marketplace.

The Action remains part of the main `sponge-b0b/arid` repository and continues to use normal Arid release tags such as `v2.2.3`. This release does not create a separate Action repository or introduce a separate Action versioning scheme.

## GitHub Marketplace metadata

The root `action.yml` now uses Marketplace-facing metadata:

```yaml
name: Arid duplicate-code check
description: Detect duplicate Python code with Arid and expose findings, metrics, and CI outputs.

branding:
  icon: layers
  color: orange
```

GitHub Marketplace supports only its predefined Feather icons and branding colors, so the Action correctly uses the supported `layers` icon and `orange` color.

This release makes the tagged Action source Marketplace-ready. It does **not** mean the Action has already been published to GitHub Marketplace; Marketplace publication is a separate GitHub UI step after this release.

## Arid brand assets

The repository also includes approved Feather-style Arid assets:

- `assets/arid-feather-solid.svg`
- `assets/arid-feather-solid.png`

The custom assets use Arid's brand amber `#F39E0A`. They remain repository branding assets; GitHub Marketplace does not accept arbitrary custom Action icons or colors in `action.yml`.

## Compatibility

Arid's duplicate-detection behavior, output contracts, suppression semantics, and existing user-facing analysis behavior are unchanged in 2.2.3. The changes in this patch are limited to Marketplace preparation, release/integration metadata, documentation, and release-process housekeeping already present on `main`.

Existing GitHub Action inputs and outputs remain unchanged.

## Install

With uv:

```bash
uv tool install --upgrade "arid==2.2.3"
arid --version
```

Or with pip:

```bash
python -m pip install --upgrade "arid==2.2.3"
arid --version
```

Expected version output:

```text
arid 2.2.3
```

## Official GitHub Action

Pin the patch release directly:

```yaml
- uses: sponge-b0b/arid@v2.2.3
  with:
    paths: .
```

After the release is published and verified, `v2.2.3` is the tag intended for the subsequent GitHub Marketplace publication step.
